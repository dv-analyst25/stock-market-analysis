# 📈 Stock Market Analysis Using Python

## 📌 Project Overview

This project analyzes historical stock market data for **Apple Inc. (AAPL)** using Python.

The objective is to understand stock price trends, daily returns, trading activity, volatility, and historical performance using data analysis and visualization techniques.

The analysis covers Apple's historical stock data from **2020 to 2024**.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze historical stock price movements.
- Understand daily return patterns.
- Analyze trading volume and market activity.
- Identify short-term and long-term price trends using moving averages.
- Measure historical volatility.
- Calculate maximum drawdown to understand downside risk.
- Analyze cumulative and annual returns.
- Identify patterns in average daily returns across different months.
- Derive meaningful insights from historical market data.

## 📂 Dataset

The dataset contains historical Apple stock market data from **2020 to 2024**.

### Features

| Column | Description |
|---|---|
| Date | Trading date |
| Open | Opening price of the trading day |
| High | Highest price during the trading day |
| Low | Lowest price during the trading day |
| Close | Closing price of the trading day |
| Volume | Number of shares traded |
